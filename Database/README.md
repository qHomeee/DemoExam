# Импорт каталога

`catalog.sql` подготовлен из оригинальных `Products_import.xlsx`, `Sizes_import.xlsx`, `Stock_Items_import.xlsx` в `ExamMaterials/Data`.

Скрипт создаёт только схему `catalog` с четырьмя таблицами. Используется отдельная БД `demoformuhin`. Повторное выполнение не удаляет и не перезаписывает существующие записи.

Нормализация ключей при связывании строк и одно явное сопоставление сокращённого названия описаны в `ExamMaterials/README.md`. Суммы остатков не уменьшаются на исторические заказы: импортируется именно колонка «Количество доступное для заказа» из исходного файла.

Это только модель каталога. Полная модель заказов, пользователей и ролей остаётся следующим этапом.
