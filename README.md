# Чудо Обувь

Демонстрационное приложение для заказа обуви по образцу ГИА ДЭ БУ КИМ 09.02.07-2-2027. Используются C#, Avalonia UI 12.1.3, MVVM, Entity Framework Core и PostgreSQL.

## Запуск и перенос

Для сборки нужен .NET SDK 10. Выбор SDK закреплён в `global.json`. Для запуска приложения нужен .NET Runtime 8.0. Обе версии могут быть установлены одновременно.

1. Скопировать репозиторий целиком. Папки `bin`, `obj` и локальные настройки копировать вместе с исходниками не требуется.
2. Создать в PostgreSQL базу `demoformuhin` и выполнить в ней `Database/catalog.sql` через pgAdmin или DBeaver. Для старой базы с каталогом и пользователями достаточно `Database/orders.sql`. Если таблиц пользователей ещё нет, сначала выполнить `Database/users.sql`.
3. В папке проекта выполнить команды PowerShell:

```powershell
New-Item -ItemType Directory -Path .local -Force | Out-Null
Copy-Item .\connection-string.example.txt .\.local\connection-string.txt
```

4. Указать в `.local/connection-string.txt` адрес PostgreSQL, имя базы, пользователя и его пароль. Можно использовать владельца созданной базы или отдельную роль с перечисленными ниже правами. Файл с паролем исключён из Git.
5. Проверить подключение и запустить:

```powershell
dotnet --version
dotnet run -- --check-db
dotnet run
```

Приложение подключается к заранее подготовленной базе. SQL выполняется отдельно в СУБД. Для чистого импорта диагностика выводит 31 модель, 92 позиции остатков, 1274 пары, 20 пользователей, 10 заказов и 30 позиций заказов. При первой сборке нужен доступ к NuGet или локальный кэш пакетов.

### Права отдельной роли PostgreSQL

Выполнить в базе `demoformuhin` от владельца после импорта. Вместо `demoformuhin_app` указать имя своей роли.

```sql
GRANT CONNECT ON DATABASE demoformuhin TO demoformuhin_app;
GRANT USAGE ON SCHEMA catalog TO demoformuhin_app;
GRANT SELECT ON ALL TABLES IN SCHEMA catalog TO demoformuhin_app;
GRANT INSERT, UPDATE, DELETE ON catalog.orders, catalog.order_items TO demoformuhin_app;
GRANT USAGE ON SEQUENCE catalog.orders_id_seq TO demoformuhin_app;
GRANT UPDATE (available_quantity) ON catalog.product_sizes TO demoformuhin_app;
```

## Что показать преподавателю

1. Открыть каталог без входа. В гостевом режиме доступны каталог и карточки товаров. Модели с остатком от 0 до 3 пар подсвечиваются красным.
2. Войти как `asidorova` без пароля. Выбрать категорию, переключить сортировку по цене и ввести часть названия или описания. Открыть модель, выбрать размер, добавить её в корзину. В корзине изменить количество или удалить позицию, затем подтвердить заказ. Остаток в каталоге уменьшится.
3. Войти как `papetrov`. Открыть «Заказы» и выбрать «Состав заказа». Показать дату, клиента, модели, размеры, цены и итог. Кнопка «Новый заказ» возвращает в каталог для выбора товаров, а в корзине сотрудник выбирает клиента.
4. Войти как `isivanov`. В составе созданного заказа поменять дату и убрать одну из нескольких позиций. При сохранении пары вернутся в остаток. Менеджер и администратор могут удалить заказ целиком с таким же возвратом остатка.

## Расчёт цены и сохранение заказа

- Для скидки берутся даты с первого числа прошлого месяца до первого числа текущего месяца. Если за этот период модель ни разу не заказывали, цена умножается на 0,75 и округляется до копеек. Даты и цены исторических заказов сохранены из Excel. Если в прошлом месяце нет заказов, скидка действует на весь каталог.
- В корзине позиция определяется парой «модель + размер». Повторный выбор увеличивает количество этой позиции. Подтверждение заново проверяет цену и остаток в базе. Заказ, цены на момент покупки и списание пар сохраняются одной транзакцией. При изменении состава и удалении заказа пары возвращаются в остаток.

## Файлы

- `Database/ER-diagram.pdf` — таблицы, ключи и связи схемы PostgreSQL.
- `Database/catalog.sql` — структура и исходные данные из пяти таблиц Excel.
- `Assets` — изображения товаров, заглушка, логотип и иконка. Они входят в сборку.
- `ExamMaterials` — КИМ, приложения и оригинальные данные.

Собрать папку для запуска в Windows x64:

```powershell
dotnet publish -c Release -r win-x64 --self-contained false -o bin\publish\win-x64
```

На другой компьютер переносится вся папка публикации. В ней запустить `DemoForMuhin.exe`. Если на компьютере нет репозитория, создать локальный файл настроек `.local\connection-string.txt` рядом с исполняемым файлом. PostgreSQL и .NET Runtime 8.0 нужны на компьютере запуска или, для PostgreSQL, на доступном сервере.

Материалы, опубликованные ИРПО, описывают общие задания. Вариативную часть профильного уровня определяет колледж.
