# Чудо Обувь

Черновик приложения на Avalonia UI с MVVM. Текущий этап — чтение каталога из PostgreSQL через Entity Framework Core.

## Запуск на этом компьютере

В PowerShell из папки проекта:

```powershell
dotnet run
```

В окне нажать **Загрузить товары**. Или запустить `Scripts/Run-Demo.ps1`.

Подключение уже настроено в `.local/connection-string.txt`. Файл исключён из Git. Приложение использует отдельную роль `demoformuhin_app` и базу `demoformuhin`. Пароль администратора в проект не записан.

## Что сделано

- Простой список товаров из БД: фото, наименование, категория, подкатегория, производство, состав, цена, суммарный остаток.
- Данные из официального приложения к КИМ 09.02.07-2-2027: 31 товар, 35 размеров, 92 записи остатков, 1274 пары.
- Связанные таблицы `catalog.categories`, `catalog.products`, `catalog.sizes`, `catalog.product_sizes`.
- Дробные размеры сохраняются без округления.
- Оригинальные фотографии, логотип, иконка, заглушка и базовые цвета из приложения.
- Подсветка остатка ≤ 3 и маркировка «много»/«мало».
- Повторная загрузка и сообщение при ошибке подключения.

## Что пока не сделано

Скидка по истории заказов, авторизация, поиск, фильтрация, сортировка, оформление и управление заказами, полный состав экзаменационной БД и ER-диаграмма. На экране показана **исходная цена из Excel**, без расчёта скидки. Пользователи и заказы пока не импортируются. Это промежуточный результат, а не готовая работа для ГИА.

## Где смотреть код

- `Models` — сущности каталога.
- `Data/CatalogDbContext.cs` — соответствие сущностей таблицам.
- `ViewModels/MainViewModel.cs` — команда загрузки и коллекция товаров.
- `Views/MainWindow.axaml` — разметка списка и привязки.
- `Presentation` — отображение изображения и цвета остатка.
- `Database/catalog.sql` — структура и исходные данные каталога.
- `ExamMaterials` — все материалы со страницы варианта.

## Настройка на другом компьютере

Нужны .NET 8 SDK и PostgreSQL. Выполнить:

```powershell
powershell -ExecutionPolicy Bypass -File .\Scripts\Setup-Database.ps1 -PostgresBin 'C:\Program Files\PostgreSQL\18\bin'
```

Скрипт запросит пароль администратора, создаст отдельную БД и роль, сохранит локальную строку подключения и импортирует каталог. Он не изменяет существующую БД с таким же именем. Путь к PostgreSQL на текущем компьютере: `X:\SQL\bin`.

Повторить импорт или проверить подключение:

```powershell
dotnet run -- --import-data
dotnet run -- --check-db
```

Повторный импорт пропускает существующие строки и не сбрасывает изменённые данные.

## Проверка

```powershell
dotnet run --project .\Verification\DemoForMuhin.Verification.csproj
```

Проверяются исходные количества, дробные размеры, привязка кнопки, загрузка фотографий, повторная загрузка и восстановление после ошибки подключения. Проверка рассчитана на исходный набор данных. Снимки окна сохраняются в `artifacts`.

## Короткий показ преподавателю

1. Запустить приложение и загрузить товары.
2. Показать фотографии и данные из исходного Excel.
3. Показать таблицы схемы `catalog` в PostgreSQL.
4. Объяснить цепочку: кнопка → команда ViewModel → DbContext → коллекция → Binding.
5. Назвать следующие шаги: разобраться в привязках, затем реализовать скидки и авторизацию.

История изменений: `git log --oneline`. Коммиты отражают реальные этапы: шаблон, первоначальный слой данных, замена набора данными варианта, упрощение интерфейса и проверка.
