# Чудо Обувь

Приложение на C# с Avalonia UI, MVVM и Entity Framework Core. При запуске открывается окно входа. Каталог читается из заранее созданной базы PostgreSQL. Приложение не создаёт таблицы и не импортирует данные.

## Запуск

```powershell
dotnet run
```

Настройки подключения находятся в `.local/connection-string.txt`. Этот файл не входит в Git.

## Вход

Вход выполняется только по логину из `Users_import.xlsx`, без пароля, как в задании. В БД подготовлены 20 пользователей и три роли. В каталоге справа сверху отображаются ФИО и роль пользователя. Кнопка «Выйти» возвращает к окну входа и очищает текущего пользователя.

Примеры логинов:

| Логин | Роль |
| --- | --- |
| `isivanov` | Администратор |
| `papetrov` | Менеджер |
| `asidorova` | Авторизованный пользователь |

Кнопка «Просмотреть каталог без входа» открывает гостевой просмотр. Для пустого и неизвестного логина выводится сообщение. Ошибка подключения к БД обрабатывается без закрытия приложения.

Для уже существующей базы без пользователей выполнить `Database/users.sql` через pgAdmin или DBeaver. Скрипт добавит таблицы `catalog.roles`, `catalog.users` и исходные записи из Excel. Приложение SQL-файлы не запускает.

## Каталог

Отображаются фотография, наименование, категория, подкатегория, производство, состав, цена и суммарный остаток по размерам. Товары с остатком не более трёх пар выделяются цветом. При отсутствии фотографии используется заглушка.

В базе: 31 товар, 35 размеров, 92 записи остатков, всего 1274 пары; 20 пользователей и три роли.

Исходные Excel-таблицы находятся в `ExamMaterials/Data`. Материалы задания и оригинальные архивы сохранены в `ExamMaterials`. В `Database/catalog.sql` сохранён отдельный SQL-файл структуры и данных. Приложение его не использует и не копирует в сборку.

## Перенос на другой компьютер

В Git включены исходники проекта, все 34 файла из `Assets`, SQL-файл БД и материалы экзамена. Изображения встраиваются в приложение при сборке. Папки `bin` и `obj` переносить не нужно.

1. Установить .NET 8 SDK и PostgreSQL.
2. Скопировать или клонировать репозиторий целиком.
3. В pgAdmin или DBeaver создать базу `demoformuhin` и выполнить в ней `Database/catalog.sql`. Скрипт восстановит каталог, пользователей и роли; приложение его не запускает.
4. В папке проекта подготовить локальную настройку подключения:

```powershell
New-Item -ItemType Directory -Path .local -Force | Out-Null
Copy-Item .\connection-string.example.txt .\.local\connection-string.txt
```

5. Открыть `.local/connection-string.txt` и указать адрес PostgreSQL, имя пользователя и свой пароль вместо `CHANGE_ME`.
6. Проверить подключение и запустить приложение:

```powershell
dotnet run -- --check-db
dotnet run
```

При первом запуске .NET восстановит NuGet-пакеты; для этого нужен доступ к источнику пакетов. Настоящий пароль остаётся в локальном файле и не попадает в Git. В репозитории хранится только `connection-string.example.txt` с примером.

## Текущий этап

Реализованы вход по логину, выход, отображение ФИО и роли, гостевой просмотр каталога. Скидки, поиск, фильтрация и работа с заказами пока не реализованы. Цена отображается без скидки, как в исходном файле.
