# Чудо Обувь

Приложение на C# с Avalonia UI, MVVM и Entity Framework Core. При открытии окна выводится каталог из PostgreSQL.

## Запуск

```powershell
dotnet run
```

Настройки подключения находятся в `.local/connection-string.txt`. Этот файл не входит в Git.

## Каталог

Отображаются фотография, наименование, категория, подкатегория, производство, состав, цена и суммарный остаток по размерам. Товары с остатком не более трёх пар выделяются цветом. При отсутствии фотографии используется заглушка.

В базе: 31 товар, 35 размеров, 92 записи остатков, всего 1274 пары.

Исходные Excel-таблицы находятся в `ExamMaterials/Data`. Материалы задания и оригинальные архивы сохранены в `ExamMaterials`. Структура таблиц и данные каталога — в `Database/catalog.sql`.

## Подключение на другом компьютере

Нужны .NET 8 SDK и PostgreSQL. Для создания отдельной базы и импорта каталога:

```powershell
powershell -ExecutionPolicy Bypass -File .\Scripts\Setup-Database.ps1 -PostgresBin 'C:\Program Files\PostgreSQL\18\bin'
```

Скрипт запросит пароль администратора. Путь к PostgreSQL на текущем компьютере: `X:\SQL\bin`.

Проверить подключение:

```powershell
dotnet run -- --check-db
```
